# Event Analytics — Frontend

React + Vite client for the real-time event analytics API.

## Run

```bash
cd Frontend
npm install
npm run dev
```

Open the URL Vite prints. With the API on `http://127.0.0.1:8000`, requests to `/events`, `/analytics`, `/health`, and `/ws` are proxied automatically.

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run preview` — preview production build
- `npm run lint` — ESLint
